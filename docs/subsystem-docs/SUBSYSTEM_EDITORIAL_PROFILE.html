01 — Propósito

Qué es el subsistema Editorial Profile

Editorial Profile es el subsistema que captura quién es el editor como comunicador y proporciona ese conocimiento como contexto activo a todos los subsistemas que producen texto. Es el único componente del sistema que modela al humano — no a un proceso ni a un artefacto.

Sin un Perfil Editorial activo, el sistema puede investigar y escribir, pero el texto resultante carece de identidad autoral. Es técnicamente correcto pero editorialmente genérico — podría haberlo escrito cualquiera. El Perfil Editorial es lo que convierte la producción asistida en autoría asistida.

El Perfil Editorial no es un conjunto de instrucciones de estilo. Es un modelo de la voz del editor construido a partir de sus propios textos, sus propias decisiones y sus propias correcciones sobre los textos producidos por el sistema.

Qué produce

El subsistema produce dos artefactos con distinto alcance y ciclo de vida:

Artefacto principal
Editor Profile
Alcance: Todos los proyectos del editor
Creación: Una vez, antes del primer proyecto
Actualización: A medida que el editor crece o cambia
Archivo: EDITOR_PROFILE_[nombre].md
Captura la voz, registro, recursos literarios, estructuras preferidas y restricciones del editor como comunicador. Es el input de estilo de todos los workflows de producción.
Artefacto ligero
Editor Notes
Alcance: Un proyecto específico
Creación: Al inicio de cada proyecto
Actualización: Durante la producción
Archivo: EDITOR_NOTES_[proyecto].md
Captura las instrucciones, preferencias y decisiones editoriales específicas de ese proyecto — lo que el Editor Profile no puede saber porque es particular de ese libro o post.

Dónde se usa el perfil

Writing
Escritura
Input obligatorio en todos los prompts de escritura — libro y post. Regula voz, tono y registro del texto producido.
Activation
Activación
Input del proceso de minería de seeds y escritura de contenido derivado. Asegura que la activación mantiene la voz del editor.
Evaluation
Evaluación
Input de EVALUATE_BOOK_STYLE y EVALUATE_POST. Sin el perfil, los evaluadores de estilo no pueden juzgar si el texto es fiel a la voz del editor.
02 — Conceptos clave

El modelo conceptual

El subsistema opera con varios conceptos que definen qué captura el perfil, cómo se construye y cómo se complementa con otros artefactos durante la producción.

Qué captura el Perfil Editorial

El perfil no es una lista de instrucciones de formato. Es un modelo de la identidad comunicativa del editor — las decisiones conscientes e inconscientes que hacen que sus textos sean reconociblemente suyos.

Dimensión 1
Voz y tono
Persona gramatical dominante, nivel de formalidad, actitud hacia el lector, densidad de prosa, ritmo de las frases. La diferencia entre un editor que escribe con distancia analítica y uno que escribe con cercanía conversacional.
Dimensión 2
Arquitectura narrativa
Cómo estructura el editor sus argumentos: ¿deduce o induce? ¿parte del ejemplo o parte del concepto? ¿usa analogías o prefiere la evidencia directa? ¿cómo construye los cierres de sección?
Dimensión 3
Recursos literarios
Metáforas recurrentes, tipos de ejemplos preferidos, uso de la ironía, referencias culturales habituales, maneras de introducir una cita o un dato estadístico.
Dimensión 4
Restricciones — NO-GOs
Lo que el editor evita sistemáticamente: clichés específicos, estructuras que no le son propias, registros que le resultan ajenos, tipos de apertura que no usa nunca.

Cómo se construye el perfil

El perfil se construye por análisis de textos del propio editor. Cuantos más textos y más variados, más preciso y robusto es el modelo. El sistema analiza las fuentes disponibles en orden de relevancia:

01
Textos propios del editor
Posts, artículos, libros, notas de trabajo. Son la fuente más directa de la voz real. Tienen prioridad absoluta sobre cualquier otra fuente.
02
Documentos de proceso
Outlines, planes narrativos, notas de trabajo, borradores descartados. Revelan cómo piensa el editor antes de escribir — información que los textos pulidos no siempre muestran.
03
Feedback e información biográfica
Correcciones históricas sobre textos, formación académica, áreas de especialización, intereses intelectuales que dan contexto al perfil.

Un perfil construido sin textos propios del editor es un perfil débil. El sistema puede producir un perfil provisional a partir de información biográfica, pero hasta que no se analicen textos reales del editor, el modelo de voz será genérico.

Editor Profile vs Editor Notes

El Editor Profile captura la identidad autoral del editor a lo largo del tiempo. Las Editor Notes capturan las decisiones específicas de un proyecto concreto que no forman parte de la identidad permanente del editor — el tono particular de un libro, el ángulo editorial de una serie de posts, las restricciones de extensión de una publicación.

El Perfil de Publicación

Independiente del Editor Profile, el sistema gestiona también Perfiles de Publicación. Un editor puede escribir para varias publicaciones con criterios editoriales distintos — un blog personal, una revista académica, un newsletter de divulgación. Cada publicación tiene su propio perfil con sus propios criterios.

La relación entre editor y publicación es de muchos a muchos: un editor puede tener múltiples publicaciones, y una publicación puede tener múltiples editores colaboradores. Por eso el Perfil de Publicación vive como entidad independiente — no dentro del Editor Profile. La conexión entre ambos se establece en el contexto de cada proyecto.

Recursos editoriales del sistema

El subsistema mantiene dos recursos de referencia que informan la construcción del perfil y orientan las decisiones editoriales de cada proyecto:

Recurso
Editorial Style
Catálogo de estilos editoriales disponibles en el sistema: los registros, tonos y aproximaciones narrativas que el sistema puede modelar. El editor selecciona el estilo que mejor describe su voz o el que quiere desarrollar para un proyecto específico.
Recurso
Book Types
Catálogo de los tipos de libro que el sistema soporta, con sus características estructurales, narrativas y de audiencia. Orienta la decisión sobre qué tipo de libro es adecuado para un determinado material de investigación.
03 — Guía de uso

Cómo configurar y mantener el perfil

El Perfil Editorial se crea una vez y se mantiene vivo. Esta sección describe cuándo crear el perfil, cómo usarlo durante la producción y cómo actualizarlo cuando el editor evoluciona.

Crear el perfil — proceso paso a paso

1
Reunir textos propios
Recopilar 3–5 textos representativos del propio editor: posts, artículos, capítulos, notas largas. Cuanto más variados en tema y formato, mejor. Si no hay textos propios todavía, empezar con documentos de proceso y actualizar el perfil cuando se acumule producción.
↓
2
Ejecutar PROMPT_CREATE_EDITOR_PROFILE
El sistema analiza todos los materiales disponibles y produce el EDITOR_PROFILE siguiendo el TEMPLATE_EDITOR_PROFILE. El proceso incluye análisis de voz y tono, identificación de arquitectura narrativa, extracción de recursos literarios recurrentes y definición de NO-GOs.
→ PROMPT_CREATE_EDITOR_PROFILE v1.1 · TEMPLATE_EDITOR_PROFILE v1.0
↓
3
Revisar y validar el perfil
El editor lee el perfil producido y verifica que el modelo de voz es reconociblemente suyo. Puede añadir, corregir o matizar cualquier dimensión. El perfil validado es la referencia canónica para todos los proyectos siguientes.
↓
4
Asignar a los proyectos activos
El perfil validado se carga como input en todos los workflows de producción. Si el editor tiene perfiles distintos para tipos de proyecto distintos, se selecciona el perfil activo correspondiente al proyecto en curso.
→ Destino: Writing (todos los prompts) · Activation · Evaluation

Usar Editor Notes durante la producción

Al inicio de cada proyecto se crea un documento de Editor Notes ligero que complementa al perfil con las decisiones específicas de ese proyecto. Las notas se van ampliando durante la producción cada vez que el editor toma una decisión que no está en el perfil general:

  • →El tono de este libro es más formal que el perfil general del editor — los capítulos de análisis deben evitar el registro conversacional que usa habitualmente.
  • →Este post va dirigido a una audiencia técnica que ya conoce el tema — no explicar conceptos básicos, asumir conocimiento previo.
  • →El primer capítulo revisado mostró que el editor prefiere párrafos más cortos de lo habitual en este libro — incorporar al estilo del proyecto.

Las Editor Notes son el mecanismo de aprendizaje proyecto a proyecto. Si una instrucción de las notas empieza a aparecer en todos los proyectos, es señal de que debe incorporarse al perfil general.

Cuándo actualizar el perfil

El Perfil Editorial no es estático. El editor evoluciona como comunicador y el perfil debe reflejar ese crecimiento. Las señales que indican que el perfil necesita actualización:

  • 01El editor corrige sistemáticamente el mismo tipo de elemento en varios proyectos seguidos — señal de que el perfil no ha capturado bien esa dimensión.
  • 02El editor ha producido un cuerpo nuevo de textos relevantes que representan una evolución de su voz respecto a los textos con los que se construyó el perfil.
  • 03El editor quiere desarrollar un nuevo registro para un tipo de proyecto diferente — se crea un perfil adicional para ese contexto sin modificar el perfil principal.
