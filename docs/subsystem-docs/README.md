## Overview

Subsystem implementation documents answer the question: *how does this subsystem work?*

Each document covers one subsystem: its role, artifacts inventory, internal flow, interfaces with other subsystems, and known gaps.

These are **pull documents** — derived from Decision Log entries and subsystem context files.

## Standards

All documents must follow **BRAND_DOC_SYSTEM v1.0** (`docs/BRAND_DOC_SYSTEM_v1_0.html`).

Update subsystem docs when:
- A new DL entry marks a significant change to the subsystem
- New prompts or artifacts are added
- Interfaces between subsystems change
