## Overview

System design documents answer the question: *why is D-X-OPUS designed this way?*

These are **pull documents** — derived from Decision Log entries produced by the development chats. The DOCS subsystem reads DL entries with status OPEN, produces the documentation, and marks them as INTEGRATED.
