# docs/

**Directory:** `docs/`  
**Purpose:** All D-X-OPUS system documentation by audience  
**Owner:** docs-dev chat  
**Updated:** May 2026 (R1 — first documentation set)

---

## Overview

This directory contains all documentation produced by the DOCS subsystem. Documents are organized by audience — each subdirectory answers a different question for a different reader.

Documentation in this directory follows the **BRAND_DOC_SYSTEM v1.0** visual identity defined in `BRAND_DOC_SYSTEM_v1_0.html`.

---

## Structure

| Directory | Audience | Question answered |
|---|---|---|
| `editor-manuals/` | Editors using the system to write | How do I use D-X-OPUS? |
| `system-design/` | Architects and decision-makers | Why is the system designed this way? |
| `subsystem-docs/` | Developers working on a subsystem | How does this subsystem work? |
| `developer-manuals/` | New developers joining the project | How do I get up to speed? *(planned)* |

## Maintenance

- Update `INDEX.html` when new documents are added to any subdirectory
- All new documents must follow `BRAND_DOC_SYSTEM_v1_0.html` standards
- Version numbers go in the document YAML header and changelog — not in the filename
