# DECISION LOG ENTRY: DL_20260506_SYSTEM_036

## DECISION

Hotfix v1.4.1: corregir 5 bugs de incompatibilidad encontrados durante el primer test E2E completo del flujo TA_Bottom_Up con entorno limpio (TC-3.1 New User Journey). Bumpar versiones a TOOL_SETUP_EDITOR_ENVIRONMENT v1.1.1 y TOOL_CREATE_PROJECT v1.1.0.

## RATIONALE

El test E2E reveló que TOOL_CREATE_PROJECT v1.0 fue diseñado asumiendo una arquitectura de carpetas con `_system/` y `_editor/` que nunca llegó a implementarse en TOOL_SETUP_EDITOR_ENVIRONMENT. Este nunca instaló dicha estructura — usa una arquitectura flat (`D-X-OPUS/prompts/`, `templates/`, etc.). Los bugs bloqueaban completamente la creación de proyectos desde un entorno limpio.

## BUGS FOUND & FIXED

| # | Tool | Bug | Fix |
|---|---|---|---|
| 1 | TOOL_SETUP_EDITOR_ENVIRONMENT | `SpreadsheetApp.getUi()` falla en proyectos standalone de Apps Script | Reemplazado por `const ui = null` |
| 2 | TOOL_CREATE_PROJECT | `validateSetup()` busca `_system/` y `_editor/` que no existen en estructura flat | Reescrito para buscar `D-X-OPUS/prompts/` (estructura real) |
| 3 | TOOL_CREATE_PROJECT | `ESSENTIAL_PROMPTS` lista 8 archivos que no existen en el package instalado | Actualizado a los 12 prompts realmente presentes en v1.4.0 |
| 4 | TOOL_CREATE_PROJECT | `generatePromptsPackage()` busca `_system/prompts/` — path inexistente | Corregido a `D-X-OPUS/prompts/` (flat) |
| 5 | TOOL_CREATE_PROJECT | Syntax error en `generateProjectReadme()` línea ~266: comilla sin cerrar en string literal de array | Corregida comilla y coma faltantes |
