# DECISION LOG ENTRY: DL_20260504_SYSTEM_029

## DECISION

Renombrar herramienta principal de creación de proyectos: `TOOL_SETUP_PROJECT_ENHANCED.gs` → `TOOL_CREATE_PROJECT.gs`

## RATIONALE

**Problema identificado:** El nombre actual genera confusión arquitectónica:
- "SETUP_PROJECT" sugiere configuración de un proyecto específico (NIVEL 2)
- En realidad es la herramienta del editor para crear múltiples proyectos (NIVEL 1)  
- "ENHANCED" no añade información útil
- Naming largo y poco intuitivo

**Solución:** `TOOL_CREATE_PROJECT.gs` es más claro:
- Función evidente: crear proyectos (no configurar uno específico)
- Scope claro: herramienta reutilizable del editor
- Nivel claro: herramienta del NIVEL 1 que ejecuta NIVEL 2
- Nombre conciso y memorable

**Coherencia arquitectónica:**
```
TOOL_CREATE_PROJECT.gs = herramienta para crear proyectos (múltiples)
PROJECT_README.md = configuración de un proyecto específico
```

## AFFECTED SUBSYSTEMS

- **SYSTEM:** Toda la documentación de setup
- **DOCS:** Guías y manuales que referencien la herramienta
