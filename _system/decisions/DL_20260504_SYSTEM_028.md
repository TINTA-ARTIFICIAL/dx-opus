# DECISION LOG ENTRY: DL_20260504_SYSTEM_028

## DECISION

Se implementa arquitectura de auto-save genérico universal para todos los artefactos de D-X-OPUS R1. Todos los workflows (Research, Writing Book, Writing Post, Activation) guardan automáticamente sus outputs en Drive con naming estándar y metadata completa.

## RATIONALE

**Problema identificado:** Solo POST_DRAFT tenía auto-save, el resto de artefactos requerían copia manual. Esto genera fricción operativa significativa y riesgo de pérdida de material.

**Solución:** Sistema genérico de auto-save que cualquier prompt puede invocar:
- Configuración centralizada en AUTO_SAVE_CONFIG.yaml
- Función AUTO_SAVE_ARTIFACT() reutilizable
- Naming estándar: `{PROJECT_CODE}_{WORKFLOW}_{TIPO}_{identifier}_v{version}.md`
- Metadata automática según nivel (standard/extended)

**Beneficios:**
- Editor no gestiona archivos manualmente
- Naming consistente automático  
- Versionado automático
- Metadata rica para troubleshooting
- Escalabilidad para futuros workflows

## AFFECTED SUBSYSTEMS

- **RESEARCH:** PROMPT_SUMMARIZE_REFERENCES v4.1 → v4.2 con auto-save
- **WRITING:** PROMPT_WRITE_POST v2.0 → v2.1 con auto-save genérico  
- **WRITING:** Todos los prompts de RAMA BOOK necesitan integración
- **ACTIVATION:** Todos los prompts necesitan integración
- **EVALUATION:** EVALUATION_RESULT necesita auto-save
- **SYSTEM:** PROMPT_PROJECT_DISCOVERY produce PROJECT_NOTES con auto-save
